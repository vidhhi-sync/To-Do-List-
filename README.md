# To-Do List Application

# About the Project
The To-Do List Application is a simple, menu-driven Python project that helps users manage their daily tasks efficiently. It allows users to add new tasks, update existing tasks, remove tasks, and view their task list through an interactive command-line interface.

This project was developed to practice Python programming concepts such as functions, lists, conditional statements, loops, and user input.

# Features
- Add Tasks: Add new tasks to your list.
- Update Tasks: Modify existing tasks.
- Remove Tasks: Delete tasks that are no longer needed.
- Display Tasks: View all tasks in the list.
- Exit: Exit the application whenever required.

# Technologies Used
- Programming Language:Python 3
- Concepts: Lists, Functions, Loops, Conditional Statements, and User Input

# How to Run the Project

1. Clone this repository:
   ```bash
   git clone https://github.com/vidhhi-sync/To-Do-List-.git
   ```

2. Navigate to the project folder:
   ```bash
   cd To-Do-List-
   ```

3. Run the Python program:
   ```bash
   python To-do-list.py
   ```

# How to Use
1. Run the program.
2. Select an option from the displayed menu.
3. Enter the task details as requested.
4. Continue managing your tasks using the available options.
5. Select Exit to close the application.
